## Как собрать APK
1. GitHub → **+ → New repository**, имя `callcenter`, Create.
2. **uploading an existing file** → перетащи всё из папки (www, resources, store, package.json, capacitor.config.json, privacy.html, README.md, build-apk.yml) → Commit.
3. Папка `.github` при перетаскивании теряется. Создай вручную: **Add file → Create new file**, имя `.github/workflows/build-apk.yml`, вставь содержимое файла `build-apk.yml` → Commit.
4. Вкладка **Actions** → жди зелёную галочку (5–10 минут).
5. Открой запуск → внизу **Artifacts → CallCenter-APK** → скачай, распакуй, установи `app-debug.apk`.

Это debug-APK для установки вручную; для Google Play нужна подписанная release-сборка (AAB).
